# دليل BTEC — تطبيق موبايل (Flutter)

تطبيق عربي (RTL) لطلبة BTEC وأولياء أمورهم والمعلمين الجدد. يحتوي على 7 شاشات:
الرئيسية، التخصصات الـ14، اختبار هولاند، اختبار الرياضيات، قصص نجاح، دليل المعلم، دليل ولي الأمر.

---

## الطريقة الأسهل: احصلي على APK بدون تثبيت أي برنامج

المشروع يحتوي على ملف جاهز يبني تطبيق APK تلقائيًا "بالسحابة" عبر GitHub Actions، مجانًا بالكامل.

### الخطوات:

1. **أنشئي حسابًا على [github.com](https://github.com)** إذا لم يكن لديك واحد (مجاني).
2. **أنشئي مستودعًا (Repository) جديدًا**:
   - اضغطي على `+` أعلى الصفحة ← `New repository`
   - اختاري اسمًا مثل `btec-guide-app`، واتركيه **Public** أو **Private** (كلاهما يعمل)
   - لا تضيفي أي ملفات تلقائية (README/gitignore) — اتركي المستودع فارغًا
3. **ارفعي محتويات هذا المجلد بالكامل** إلى المستودع. أسهل طريقة بدون سطر أوامر:
   - افتحي صفحة المستودع الفارغ على GitHub
   - اضغطي `uploading an existing file`
   - اسحبي جميع ملفات ومجلدات هذا المشروع (بما فيها المجلدات المخفية مثل `.github`) وارفعيها
   - اكتبي أي رسالة ثم اضغطي `Commit changes`
4. **انتظري 3-5 دقائق**: بمجرد الرفع، سيبدأ GitHub تلقائيًا ببناء التطبيق. لمتابعة التقدم:
   - افتحي تبويب **Actions** أعلى صفحة المستودع
   - ستجدين عملية باسم "Build Android APK" قيد التشغيل (دائرة صفراء) ثم تكتمل (علامة ✅ خضراء)
5. **حمّلي ملف APK**:
   - اضغطي على العملية المكتملة (✅)
   - انزلي لأسفل إلى قسم **Artifacts**
   - حمّلي `btec-guide-apk` (سيكون ملف ZIP يحتوي على `app-release.apk`)
6. انقلي ملف الـ APK إلى هاتف أندرويد وثبّتيه (قد تحتاجين تفعيل "السماح بالتثبيت من مصادر غير معروفة" من إعدادات الهاتف).

> كل مرة ترفعين فيها تعديلًا جديدًا على الكود، سيُبنى APK جديد تلقائيًا بنفس الطريقة.

## الطريقة البديلة: بناء APK على جهازك مباشرة

إذا كان لديك Flutter مثبّتًا على حاسوبك:

```bash
flutter create --platforms=android --org com.btecguide .
flutter pub get
flutter build apk --release
```

سيكون الملف الناتج هنا: `build/app/outputs/flutter-apk/app-release.apk`

---

## الطريقة البديلة الثانية: خدمة بناء سحابية بواجهة رسومية

إذا كنت تفضّلين واجهة أسهل من GitHub Actions، يمكنك استخدام [Codemagic](https://codemagic.io) (له باقة مجانية):
ارفعي المشروع على GitHub كما في الخطوات أعلاه، ثم اربطي حساب Codemagic بمستودع GitHub واختاري "Flutter App" — سيكتشف المشروع تلقائيًا ويبني APK بضغطة زر.

## بنية المشروع

```
lib/
  main.dart                     نقطة الدخول والتوجيه بين الشاشات
  theme/app_theme.dart          الألوان والخطوط (نفس هوية الموقع)
  models/                       بيانات التخصصات، أسئلة الرياضيات، أفعال الأوامر
  screens/                      الشاشات السبع
  widgets/common.dart           عناصر مشتركة (الدرج الجانبي، البطاقات، الوسوم)
```
